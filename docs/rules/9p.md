# 9 人局规则

> 权威实现：`src/agents/rules.ts` 的 `RULES_TEXT_9P` 与 `src/engine/engine.ts`。
> 本文档给人类读者看；两者不一致时以代码和测试为准。

## 配置

| 阵营 | 角色 | 数量 |
|---|---|---|
| 狼人 | 狼人 | 3 |
| 好人 | 村民 | 3 |
| 好人 | 预言家 | 1 |
| 好人 | 女巫 | 1 |
| 好人 | 猎人 | 1 |

没有警长、守卫、白痴等扩展角色；不存在警上竞选、警徽流、守卫守护等机制。

## 胜利条件

- **狼人胜**：所有村民出局，或所有神职（预言家、女巫、猎人）出局。
- **好人胜**：所有狼人出局。
- 同一次结算中如果狼人全灭，同时好人也满足被屠边，**优先判好人胜**（狼人必须至少存活一人才能赢）。

## 夜晚

夜晚按以下顺序结算：

1. **狼人行动**
   - 存活狼人按座位顺序在狼队频道发言（可选）。
   - 每名狼人投票刀杀一名存活玩家，或选择空刀。
   - 狼队内部得票最高且唯一的目标被刀；平票或全空刀则空刀。
   - 允许自刀（刀狼队友）。
2. **预言家行动**
   - 查验一名存活玩家，不能是自己。
   - 得到“狼人”或“好人”（阵营，不是具体身份）。
   - 即使当夜被杀，也仍然完成查验。
3. **女巫行动**
   - 法官告知女巫当晚狼队刀杀的目标（可能为空刀）。
   - 可以选择：
     - 使用解药救该目标（解药一次）；
     - 使用毒药毒杀一名存活玩家，不能是自己（毒药一次）；
     - 不用药。
   - 解药和毒药不能同一晚同时使用。
   - 第一夜之后不能自救。
   - 即使女巫当夜被杀，她仍然可以完成用药。
4. **天亮结算**
   - 狼刀目标（若未被救）死亡；毒药目标死亡。
   - 死亡公告只公布座位，**不公布死因**。
   - 若无人死亡，公告“平安夜”。

## 天亮 / 遗言

- **夜晚死亡没有遗言**（狼刀、毒杀都不留遗言）。
- 若死者是猎人：
  - 死于狼刀 → 可以开枪；
  - 死于女巫毒药 → 不能开枪；
  - 死于猎人开枪（理论上只有一名猎人，不会发生）→ 不能开枪。
- 猎人可以选择放弃开枪。开枪目标必须是存活玩家。
- 被猎人带走的玩家留遗言。
- 猎人开枪结算完后检查胜负。

## 白天

1. 存活玩家按顺序依次公开发言，每人一次，最多 500 字。
2. 全体存活玩家投票：
   - 可以投给任意存活的其他玩家；
   - 不能投自己；
   - 可以弃票。
3. 得票最多且唯一者被放逐；最高票平票则无人被放逐；全弃票也无人被放逐。
4. 被放逐者留遗言。
5. 若被放逐者是猎人，可以开枪；被带走的玩家留遗言。
6. 检查胜负；未结束则进入下一夜。

## 信息规则

- 夜间行动、狼队讨论、查验结果、女巫用药都是私密信息。
- 白天发言、投票记录、死亡公告、猎人开枪、遗言、游戏结束身份公布是公开信息。
- 死亡公告不公布死因；玩家只能根据夜晚信息、女巫行为和发言自行推断。
- 出局玩家不再发言、投票或使用夜间技能；只有遗言和猎人开枪。

## 边界与约定

- 女巫被刀当夜仍可行动；如果她选择不自救，会在天亮死亡，但毒药仍然生效。
- 预言家被刀当夜仍可查验；但夜晚死亡没有遗言，所以关键查验和判断要在白天说清楚。
- 狼人自刀是允许的；女巫可以救自刀目标。
- 狼刀目标和毒药目标可以是同一人；该玩家死亡，死因同时包含狼刀和毒药（猎人因此不能开枪）。
- 平票不进入 PK 或二次投票；直接无人出局。
- 游戏最多 30 天；正常对局不会触发。触发时判中止（无胜者）。
