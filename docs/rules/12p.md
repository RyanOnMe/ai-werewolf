# 12 人局规则（预女猎白 · 上警）

> 权威实现：`src/agents/rules.ts` 的 `RULES_TEXT_12P` 与 `src/engine/engine.ts`。
> 本文档给人类读者看；两者不一致时以代码和测试为准。

## 配置

| 阵营 | 角色 | 数量 |
|---|---|---|
| 狼人 | 狼人 | 4 |
| 好人 | 村民 | 4 |
| 好人 | 预言家 | 1 |
| 好人 | 女巫 | 1 |
| 好人 | 猎人 | 1 |
| 好人 | 白痴 | 1 |

第 1 天进行警长竞选。没有守卫、白狼王、狼美人等扩展角色。

## 胜利条件

- **狼人胜**：所有村民出局，或所有神职（预言家、女巫、猎人、白痴）出局。
- **好人胜**：所有狼人出局。
- 同一次结算中如果狼人全灭，同时好人也满足被屠边，**优先判好人胜**（狼人必须至少存活一人才能赢）。

## 夜晚

按狼人 → 预言家 → 女巫顺序结算：

1. **狼人行动**
   - 存活狼人按座位顺序在狼队频道发言（可选）。
   - 每名狼人投票刀杀一名存活玩家，或选择空刀。
   - 狼队内部得票最高且唯一的目标被刀；平票或全空刀则空刀。
   - 允许自刀。
2. **预言家行动**
   - 查验一名存活玩家，不能是自己；得到“狼人”或“好人”。
   - 即使当夜被杀，也仍然完成查验。
3. **女巫行动**
   - 知道当晚狼刀目标；可以救、毒或不用药。
   - 解药、毒药各一次；不能同晚双药；第一夜之后不能自救。
   - 即使当夜被杀，她仍然可以完成用药。
4. **天亮结算**
   - 狼刀目标（若未被救）和毒药目标死亡。
   - 死亡公告只公布座位，不公布死因。
   - **夜晚死亡没有遗言。**

## 第 1 天警长竞选

1. 天亮后、白天发言前，所有存活玩家依次选择是否上警（`sheriff_run`）。
2. 上警玩家按座位顺序发表竞选发言（`sheriff_say`），所有玩家可见。
3. 只有一名候选人时自动当选；多名候选人时，由**警下玩家**（未上警的存活玩家）投票（`sheriff_vote`）。
4. 警长票选规则：
   - 得票最多且唯一者当选；
   - 平票或无人得票则本局没有警长；
   - 候选人不能投警长票；可以弃票；
   - 警长竞选只举行一次，不会因为警长死亡而重新竞选。
5. 警长在放逐投票中有 **1.5 票**。警长自己仍不能投自己；弃票时没有票权。
6. 警长死亡时（夜晚死亡、被放逐、被猎人开枪）可以移交警徽：
   - 交给一名存活玩家；或
   - 销毁警徽；
   - 警徽交接是公开事件。没有合适目标时宁可销毁，避免把 1.5 票送给狼人。

## 白痴

- 白痴属于好人阵营，是神职，计入狼人屠神目标。
- 白痴第一次被放逐时翻牌，免于出局并继续存活，但永久失去放逐投票权。
- 翻牌后再次被放逐，正常出局。
- 白痴被狼刀、毒杀或猎人开枪时正常出局，不翻牌免死。
- 白痴翻牌是公开事件；存活的白痴仍算存活神职。

## 天亮 / 遗言

- **夜晚死亡没有遗言**（狼刀、毒杀都不留遗言）。
- 若死者是猎人：
  - 死于狼刀或被放逐 → 可以开枪；
  - 死于女巫毒药 → 不能开枪。
- 猎人可以选择放弃开枪。开枪目标必须是存活玩家。
- 被猎人带走的玩家留遗言。
- 若死者是警长，先处理警徽移交，再处理猎人开枪（如果同一人同时是警长和猎人）。
- 猎人开枪结算完后检查胜负。

## 白天

1. 公布夜晚死亡；夜晚死亡没有遗言。
2. 存活玩家按顺序依次公开发言，每人一次，最多 500 字。
3. 存活且有投票权的玩家投票：
   - 可以投给任意存活的其他玩家；
   - 不能投自己；
   - 可以弃票；
   - 警长票权 1.5；
   - 翻牌白痴没有投票权。
4. 得票最多且唯一者被放逐；最高票平票则无人被放逐；全弃票也无人被放逐。
5. 被放逐者留遗言；若被放逐者是猎人，可以开枪；被带走的玩家留遗言。
6. 若被放逐者是未翻牌白痴：翻牌免死，失去投票权，不进入遗言/开枪结算。
7. 检查胜负；未结束则进入下一夜。

## 信息规则

- 夜间行动、狼队讨论、查验结果、女巫用药是私密信息。
- 白天发言、上警选择、竞选发言、警长票、警长当选、警徽交接、白痴翻牌、放逐投票、死亡公告、猎人开枪、遗言、游戏结束身份公布是公开信息。
- 死亡公告不公布死因。
- 出局玩家不再发言、投票或使用夜间技能；只有遗言、猎人开枪和警徽移交。

## 边界与约定

- 女巫被刀当夜仍可行动；如果她选择不自救，会在天亮死亡，但毒药仍然生效。
- 预言家被刀当夜仍可查验；但夜间死亡没有遗言，关键信息要在白天说清楚。
- 狼人自刀是允许的；女巫可以救自刀目标。
- 狼刀目标和毒药目标可以是同一人；该玩家死亡，死因同时包含狼刀和毒药（猎人因此不能开枪）。
- 平票不进入 PK 或二次投票；直接无人出局。
- 警长死亡时如果所有其他玩家都已出局，游戏已经结束，不再进行警徽移交。
- 游戏最多 30 天；正常对局不会触发。触发时判中止（无胜者）。
